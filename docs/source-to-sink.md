## Спостереження

- **Опис.** Alice створила інцидент `7b43f8e6-291b-40dc-9bf3-a8f9a2607ad8`. Під час читання того самого запису в окремому сеансі Morgan маркер повернув `executed`. На виправленій версії тест `description-dom.js` для запису `e06f8773-f7f8-4d01-bef8-f0f507433eb9` повернув `PASS: persisted description rendered as plain text`. Записи створено у двох навчальних БД з однаковим канонічним маркером.
- **Коментар.** Для початкового інциденту Alice `20000000-0000-0000-0000-000000000001` до виправлення отримано `imageInDescription: false`, `imageInComments: true`, `marker: "executed"`. Після виправлення той самий тест коментарів пройшов обидва завантаження без виконання маркера та без дублікатів.
- **Звичайний текст.** Опис завдовжки 4000 символів з апострофом, лапками, Unicode та фрагментом `<b>Звичайний текст</b>` повністю збігся у введеному рядку, відповіді API та DOM.

**Першопричина.** Збережений у БД текст залишався підконтрольним автору запису. Уразливість виникала під час присвоєння цього тексту властивості `innerHTML`. Після виправлення структуру документа створює код, а значення з API потрапляють у текстові вузли.
